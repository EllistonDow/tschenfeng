## 项目概览

打破传统单体电商笨重的前后端耦合束缚，基于 Python GraphQL（Saleor）与 TypeScript 模块化微架构（MedusaJS / Vendure），构建极速响应的全渠道一体化独立站零售体系。

### 核心特性
- **现代化解耦 API 数据层**：统一提供产品目录、实时购物车、自适应结算与多币种资产流。
- **iOS & Android 移动端深度适配**：结合移动端离线缓存、原生推送通知与极速下单，大幅拉升移动端复购率。
- **与 Shopify 多端生态联动**：支持跨多店铺库存治理与全渠道订单集中式自动化同步。
