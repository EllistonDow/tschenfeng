## 项目概览

打破传统单体电商的前后端耦合束缚，基于 Python + Django + GraphQL 的开源无头电商核心 **Saleor**，构建全渠道一体化零售体系。

### 核心特性
- **GraphQL 强类型数据层**：单个端点统一提供产品、购物车、结账与用户资产流。
- **iOS & Android 移动端原生适配**：深度结合移动端推送通知、离线缓存与即时结账，大幅拉升移动复购率。
- **与 Shopify 多端生态联动**：支持异构多店铺库存与全渠道订单集中式自动化同步。
