## Design Philosophy & Performance

Built around the Bento Grid visual design language, this platform presents technical credentials, live timezone indicators, interactive stack badges, and in-depth engineering field logs with aesthetic clarity.

- **Zero Client-Side JavaScript by Default**: Fully static pre-rendering delivers instant page loads while conserving mobile battery and bandwidth.
- **Zero-FOUC Dark Mode**: Inlined synchronous execution eliminates flash of unstyled content during theme transitions.
- **Type-Safe Content Collections**: Powered by Astro Content Layer for guaranteed frontmatter validation.
