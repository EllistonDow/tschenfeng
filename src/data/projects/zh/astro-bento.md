## 设计理念与性能突破

采用 Bento Grid（便当盒栅格）视觉规范，将个人简介、实时时区时钟、技术栈标签、开源作品与深度技术文章进行优雅重构。

- **默认 0 客户端脚本**：全静态构建，极度节省移动端电量与带宽。
- **自适应暗黑模式**：纯内联同步执行，彻底消除任何页面闪烁（FOUC）。
- **自动化内容集合**：全类型安全 Markdown 驱动。
