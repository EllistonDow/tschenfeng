在移动设备尤其是网络不稳定场景下，每一兆多余的 JavaScript 都在消耗用户的流量、CPU 电量与等待耐心。

现代 CSS（包括 CSS Grid、Container Queries、`prefers-color-scheme`、原生微动效）已经强大到可以替代过去 70% 用 JS 实现的纯视觉功能。拥抱静态编译，是让网站重获新生的关键一步。
